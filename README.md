
# 🌸 My Digital Space | Eloisa Reyes

## Descripción del proyecto

My Digital Space es un portal web personal desarrollado
como parte de la asignatura Diseño de Sistemas en Internet.

El sitio presenta información sobre Eloisa Reyes,
estudiante de Ingeniería en Sistemas de 21 años,
incluyendo una breve presentación personal,
sus intereses, habilidades y enlaces favoritos.

## Objetivo

Identificar y aplicar la estructura básica del frontend
mediante HTML5, organizando correctamente los elementos
de una página web personal.

## Tecnologías utilizadas

- HTML5: estructura y contenido de la página.
- CSS3: diseño visual, colores y distribución.
- Visual Studio Code: entorno de desarrollo.
- Git y GitHub: control de versiones y repositorio.

## Funcionalidades

- Presentación personal.
- Fotografía de perfil.
- Sección "Sobre mí".
- Lista de intereses y habilidades.
- Enlaces a sitios web favoritos.
- Navegación entre secciones.
- Diseño adaptable a diferentes pantallas.

## Estructura del proyecto

my-digital-space/
- index.html
- style.css
- foto-perfil.jpg
- README.md

## Ejecución

1. Descargar o clonar el repositorio.
2. Abrir la carpeta en Visual Studio Code.
3. Abrir index.html en un navegador web.
4. Explorar las diferentes secciones del portafolio.
